# PCL修复版

把新版 PCL 删掉的 **「下载 Minecraft」** 恢复了，顺便把 **联机** 修好。

> 这是第三方修改版，与龙腾猫跃及 PCL 官方**没有任何关系**。
> 上游项目：[Meloong-Git/PCL](https://github.com/Meloong-Git/PCL)

---

## 修了什么

| 功能 | 官方开源版 | PCL修复版 |
|---|---|---|
| 下载 MC 原版 / Forge / Fabric / 整合包 | ❌ 功能被移除 | ✅ **恢复** |
| 和朋友联机 | ❌ 依赖的节点已停服，打不开 | ✅ **重写，一键建房** |
| 正版登录 | ❌ 缺 ClientId，点登录就报错 | ✅ **自动跳官方启动器** |
| 离线登录、模组管理、版本隔离等 | ✅ | ✅ 原样保留，没动过 |

> 为什么官方开源版不能用？因为 PCL 的开发者把下载功能关掉了，联机依赖的公共节点也停了。
> 官方版 PCL 不受影响——它从自己的服务器拿新节点；开源版被切断了这条路。

## 下载

**[⬇ 前往 Releases 下载最新版](https://github.com/49zr664rb8-hue/PCL-repair/releases/latest)**

需要下载两个文件，**放在同一个文件夹**：

```
PCL-repair.exe
PCL-repair.exe.config     ← 必须和 exe 同名同目录
```

双击 `PCL-repair.exe` 就能用，不用安装。

> `.exe.config` 里有一项网络设置，缺了它部分下载请求会失败。
> 想显示成中文文件名，把这两个文件**一起**改名即可（比如 `PCL修复版.exe` 和 `PCL修复版.exe.config`）。

**系统要求**：Windows 10 / 11 64 位，.NET Framework 4.8（Win10 1809 以上自带，不用装）

## 怎么用

### 装游戏

1. 打开 PCL → 顶部「下载」
2. 选版本（原版 / Forge / Fabric / 整合包都行）→ 开始安装

### 和朋友联机

房主和朋友**都不需要公网 IP**，也不用装任何联机软件。

> **前提：双方网络都要有 IPv6。** 隧道走 `bore.pub` 的 IPv6（IPv4 在国内部分线路被封）。
> 不确定的话先打开 https://test-ipv6.com/ 看一下，没有就在光猫/路由器里开启。

**房主：**
1. 进游戏 → `Esc` → 「对局域网开放」→ 记下端口号
2. 回到 PCL → 顶部「联机」→「创建房间」→ 输入端口
3. 等它自动下载隧道程序（约 1.7MB，只下一次）→ 显示 `bore.pub:12345`
4. 把这串地址发给朋友

**朋友：**
1. 把地址粘到 PCL 的「加入房间」（或者复制地址后切回 PCL，会自动弹窗问要不要加入）
2. PCL 提示「打开游戏 → 多人游戏 → 直接连接，填入这串地址」
3. 进游戏连上

> 联机窗口不能关，关了隧道就断。

### 正版登录（进正版服务器、Realms 用）

PCL 里点「正版」→「登录」，会自动打开 **Minecraft 官方启动器**，在那边登录即可。

登录完关掉官方启动器，以后点 PCL 的「开始游戏」也会自动跳过去——因为正版登录只有官方启动器能做。

## 常见问题

**Q：为什么点「登录」弹出来的是官方启动器，不是 PCL 自己的登录框？**

PCL 的正版登录需要一个微软开发者凭证（ClientId），这个凭证只有 PCL 官方有，开源版里被删掉了。
自己申请需要 Azure 订阅，普通用户拿不到。所以改成借用官方启动器登录——效果一样，还能用 Realms 和披风。

**Q：在官方启动器里看不到我的 mod 和存档？**

不会。PCL 在你点「开始游戏」时，会把当前版本和它的游戏目录（mod、存档所在的位置）自动写进官方启动器的配置，
所以那边打开的就是同一个版本、同一个目录。前提是**先点 PCL 的「开始游戏」**，它才会同步。

**Q：联机地址每次都不一样？**

是的，`bore.pub` 的公共端口是随机分配的，每次建房都要重新发一次地址。

**Q：联机卡 / 掉线？**

`bore.pub` 是免费公共节点，带宽和稳定性没有保证。人多了会卡，属于正常现象。

**Q：提示「没有找到 Minecraft 官方启动器」？**

装一个就行：[Minecraft 官方启动器](https://www.minecraft.net/zh-hans/download)。
不装也能玩——离线登录时会自动回退，由 PCL 自己启动游戏。

**Q：创建房间卡住，或者报「隧道程序意外退出（代码 1）」？**

联机走的是 `bore.pub` 的 **IPv6**。它的 IPv4 地址在国内部分线路上被封（TCP 直接超时），
所以 PCL 会先探测，哪个协议通就用哪个——**但前提是你的网络得有 IPv6**。

检查一下：打开 https://test-ipv6.com/ ，如果没有 IPv6 地址，需要在光猫/路由器里开启
（现在国内宽带基本都支持，一般在「网络设置 → IPv6」里打开）。

> **你朋友那边同样需要 IPv6**，因为他也要连 `bore.pub`。两个人都没有 IPv6 的话，
> 这条路走不通，只能换用其他联机方式（比如樱花映射、Sakura Frp 之类的内网穿透服务）。

如果两边都有 IPv6 还是失败，把 PCL 日志里带 `bore` 的那几行发到 Issues——现在日志会打印
探测结果（`bore 服务端可达：...`），能直接看出卡在哪一步。
